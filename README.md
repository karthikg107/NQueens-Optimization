# N-Queens Optimization Algorithms

This project presents a comparative analysis of multiple algorithms used to solve the N-Queens problem.

## Algorithms Implemented
- Depth First Search (DFS)
- Hill Climbing
- Simulated Annealing
- Genetic Algorithm

## Features
- Runtime analysis
- Memory usage comparison
- Conflict minimization analysis
- Scalability evaluation

## Technologies Used
- Python 3.13
- Matplotlib
- NumPy
